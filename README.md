# BiomFinder

Маленький клиентский мод для Minecraft 1.7.10 (Forge 10.13.4.1614).

В экране F3 (в левой колонке, в самом низу) показывает данные биома, в котором стоит игрок:

- **Биом и его ID.**
- **Температура:** у самого биома и в этой точке. Игра делает высокие места холоднее, и от этого зависит, например, выпадет ли снег.
- **Влажность и осадки:** дождь, снег или нет.
- **Типы биома из словаря Forge:** по ним другие моды ищут биомы.

По этим данным можно точно определить и воспроизвести текущий биом без угадайки.

## Установка

Скачать jar из папки `releases` и положить в `mods`. Мод нужен только клиенту, на сервер ставить не надо.

## Сборка

```
./gradlew build
```

jar появится в `build/libs`.
